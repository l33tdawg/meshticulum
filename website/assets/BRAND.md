# Meshticulum identity

The mark forms an M from connected nodes. The center diamond represents the bridge between a small radio network and a wider network. The original SVG artwork is part of this Apache-2.0 project.

- Sage green: `#79bfa3`
- Amber: `#efb76b`
- Ink: `#101d1b`
- Paper: `#f1f0e9`

Use `meshticulum-logo.svg` for the icon and `meshticulum-wordmark.svg` on dark backgrounds. Keep their proportions and leave space around the outer nodes. Attribution: SAGE Foundation / Dhillon Andrew Kannabhiran.

The transparent `meshticulum-logo.png` is 1024 × 1024. The `social-card.png` is 1200 × 630, suitable for article link previews. Both render the original SVG artwork. With Sharp installed, regenerate them using `node tools/render_brand.cjs`; font availability can affect the social card's text rendering.
