Meshticulum has been a public source project since 2026-10-11; `1.0.0-alpha` remains unreleased. The existing programme remains active. Public source availability does not close its physical or release requirements. The following work retains the broader scope beyond recorded finite milestones.

2. Extend authenticated TCP and actual IP transport qualification with original peer/expiry/replay bindings and explicit IP accounting. Socket writes are not RF completion; IP bytes are not radio airtime.
3. Broaden the recorded C→A LoRa→B IP and separate loss/LoRa-resume/measured-IP-return campaigns. Preserve original deadlines, fresh admission, verified-piece reuse, failed observations and missing measurements across later lifecycle and topology coverage.
4. Qualify the optional private SAGE integration against the real encrypted backend and native owner, including original intention, capture, replay, expiry, consent and uncertain-write recovery.
5. Qualify Meshticulum's own sustained useful encrypted RF goodput, completion and latency, including request, response, ACK, retry and reverse-medium cost. The alpha bar is deployable code with reliable, independently verified completion and sustained useful encrypted goodput above 1,000 B/s within original deadlines. Report whole-operation setup, verification and cleanup time separately from flow/RF timing; short samples and raw bitrate do not establish sustained acceptance. Evaluate the goal of outperforming both MeshCore and Reticulum using their published figures; self-run upstream benchmark campaigns are not required. Record provenance, versions, hardware, waveform, payload, encryption, topology and timing boundaries where available, and mark missing or incomparable evidence. The broader target remains 1–1.5 kB/s useful encrypted RF goodput without completion or latency regressions; meeting that target alone does not prove superiority over both projects. The owner-requested later stretch target is 4–5 kB/s useful encrypted goodput. The retained SF7/BW500/CR4/5 profile has a nominal raw ceiling of 2,734.375 B/s before protocol overhead, so that stretch requires a faster PHY with verified radio/firmware capability and fresh bounded admission. Range at faster profiles is unmeasured.
6. Evaluate the stronger-security goal against explicit upstream security properties and a reviewed threat model. Current PSK transport and static recipient envelopes have no proved forward secrecy; Reticulum's published Link and ratchet mechanisms set a concrete property to address. Qualify key establishment, key lifecycle and compromise behavior before claiming better encryption security, preserving peer bindings, replay decisions, consent, deadlines and debt. See the [security comparison](COMPARISON.md#security-properties-and-gaps).
7. Close firmware source/deployed-image correspondence, exact third-party notices, corresponding-source/relinking materials and release review. Preserve the standalone recipe's scoped same-host reproduction evidence.
