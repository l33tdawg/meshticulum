# Transport source update

The current measured public SDK source is [`da247a1`](https://github.com/l33tdawg/meshticulum/commit/da247a1bb74601973f0bb72f51c268a412714719). It includes the reusable transport and firmware from the earlier `2b9db9e` source checkpoint, the public examples, and later host-side ownership and receipt-confirmation repairs. Package version **`1.0.0a1`** is published from source `673eb60` as the [`v1.0.0-alpha` prerelease](https://github.com/l33tdawg/meshticulum/releases/tag/v1.0.0-alpha).

On 17 October, that exact SDK source completed **two fresh 100 kB files at 1.95 to 2.03 kB/s (15.6 to 16.2 kbit/s) including sender startup** and a separate fresh 23,900-byte file at **2.535 kB/s (20.28 kbit/s)**. All used direct GFSK250 at about one metre. The [measurement report](RADIO_SDK_MEASUREMENTS.md) records whole-file timing, receiver confirmations and the remaining limits. No firmware was flashed for these samples. [Source CI for `da247a1`](https://github.com/l33tdawg/meshticulum/actions/runs/39028024473) passed on Python 3.11, 3.12 and 3.13. The selected source-build artifacts are published as the `v1.0.0-alpha` prerelease; future candidates need their own exact checks and artifacts.

The [SDK guide](SDK_GUIDE.md) retains its offline example. [Device setup](DEVICE_SETUP.md), the [firmware recipe](FIRMWARE_RECIPE.md) and [app-only flashing guide](FLASHING.md) distinguish build evidence from deployment and rollback. The [signed bundle example](../examples/BUNDLE.md) retains the original grants, boot identities, monotonic file end and attempt debt. The [post-quantum prototype](POST_QUANTUM.md) remains a separate experiment; this update does not make post-quantum cryptography the default.

Existing [performance records](PERFORMANCE.md) remain bound to their original samples and timing definitions. The current finite GFSK measurements establish no general upstream speed comparison, sustained-capacity distribution, private native qualification or firmware-release result. The source-build alpha is published; [broader qualification gates](RELEASE_READINESS.md) remain open.

Meshticulum remains independent of Lantern and the SAGE SDK. [SAGE Lantern](https://github.com/l33tdawg/sage-lantern) owns product policy, private adapters, native jobs, provisioning and deployment. A consuming application must pin the exact integrated commit and verify its required source hashes before repeating its own integration and native checks.
